# Samuel Briole Personal Website

Source for [samuelbriole.com](https://samuelbriole.com), a content-first portfolio rather than an interactive application.

## Development

Use the Node version in `.node-version` and the package manager pinned in `package.json`.

```sh
pnpm install
pnpm dev
```

Other commands are defined in `package.json`.

Public stats refresh when the site is rebuilt, not when a visitor loads the page.
